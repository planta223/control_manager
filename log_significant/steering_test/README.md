## GPS 기준 분석 결과

엔코더 표시각 24°는 신뢰할 수 없으므로 구간 선정과 조향각 계산에 사용하지 않았다.
GPS 위치·속도·측위 상태로 안정된 원선회 구간을 선정했다.

| 항목 | 우회전 | 좌회전 |
|---|---:|---:|
| GPS 안테나 궤적 반경 | 4.23m | 4.53m |
| 후륜축 중심 반경 추정 | 4.19m | 4.50m |
| GPS 역산 실효 조향각 크기 | **17.57°** | **16.45°** |
| 분석 구간 속도 중앙값 | 5.57km/h | 10.10km/h |

축간거리 1.328m, 중심선상 안테나 전방 오프셋 0.559m 및 평면 무슬립 자전거 모델을 가정했다.
실효각은 GPS 궤적에서 역산한 등가각이며 각 앞바퀴의 각도를 직접 측정한 값은 아니다.
좌우 속도 조건이 달라 정적 최대 바퀴각이나 기구의 좌우 비대칭으로 확정하지 않는다.

## 기계 한계와 제어 한계 구분

사용자 확인: 왼쪽 바퀴에서 대략 측정한 우측 조향 +17.75°, 좌측 조향 −27.27°는
**기계적인 조향 끝단**이며 이번 GPS 시험의 제어적 최대 조향과 별개다.
이 측정값을 GPS 실효각과 직접 대조해 불일치로 판단하지 않는다.

현재 보관된 조향 펌웨어 `docs/261020_firmware/steering/Core/Inc/config.h`에는 다음 설정이 있다.

| 구분 | 값과 의미 |
|---|---|
| 펌웨어 기계 한계 상수 | `STEERING_MECHANICAL_MIN/MAX_DEG = −26.47 / +26.47`, 사용자 설명상 CAD 기반 |
| 펌웨어 제어 목표 제한 | `CONTROL_TARGET_MIN/MAX_STEERING_DEG = −24 / +24`, 보드 내부 환산 단위 |
| GPS로 역산한 제어 한계 선회 실효각 | 우회전 17.57°, 좌회전 16.45° |
| 공통 실효각 모델 후보 | 위 GPS 결과의 평균인 ±17.01°, 중간 구간 선형 가정 |

보드 내부 각도와 개별 바퀴의 물리각, 자전거 모델의 등가각은 서로 구분한다.
공통 실효각 모델은 제어 목표 범위를 설명하는 값이며 기계 한계 상수를 대체하지 않는다.
이 메모를 추가하면서 펌웨어·제어 설정은 변경하지 않았다.

상세 분석·그래프·재현 코드는 워크스페이스의
`test_runs/steering-angle-analysis-20261022/README.md`, `gps_analysis.py`, `out/gps/`에 있다.
복사한 세션별 README는 당시 원문을 유지했으므로 현재 GPS 분석 판단은 이 리뷰를 기준으로 한다.

궤적 그림은 전체 GPS 위치와 원선회 선정 위치, 적합 원, 시간별 이동 및 시작·종료 위치를 표시한다.
각도 비교에서 조향 피드백은 미보정 참고값이다. GPS 각은 진행방향 yaw가 아니라 원 반경에서 역산한
등가 조향각이며, 안정 원선회 구간에만 대표값으로 표시했다. 구간 밖의 실시간 조향각을 추정한 그림은 아니다.

그림은 [make_figures.py](make_figures.py)로 생성했다. 입력·그림 해시와 원본 파일 불변성 확인은
[figure_manifest.json](figure_manifest.json)에 기록했다. 기존 로그 파일 15개는 변경하지 않았다.
