## GPS 기준 분석 결과

거리의 시작은 제동 명령 발행 시각의 GNSS 위치를 보간한 지점이다.
정지는 속도 크기 **0.1m/s 이하가 0.5초 유지되는 구간의 시작 표본**으로 정했다.
아래 정지 시간에는 이후 약 0.5초의 정지 확인 대기시간을 포함하지 않았다.

| 항목 | 10km/h | 20km/h | 30km/h |
|---|---:|---:|---:|
| 제동 명령을 유발한 관측 속도 | 10.14km/h | 20.21km/h | 30.14km/h |
| 명령 위치 → 정지 위치 직선거리 | **3.03m** | **6.69m** | **11.99m** |
| 명령 → 정지 구간 시작 | **1.98초** | **2.51초** | **3.00초** |
| 명령 이후 관측 최고속도 | 10.97km/h | 21.19km/h | 30.44km/h |
| 원본 최종 `result` 이벤트 | 있음 | **누락, 원자료 재구성** | 있음 |

10·30km/h의 기존 결과 거리와 정지 시각을 독립적으로 재현했다.
20km/h도 제동 명령·UDP 송신·정지 관측·GNSS 원자료가 남아 있으며, 최초 제동 명령을 기준으로
약 6.694m를 재구성했다. 원본 `result` 이벤트를 새로 만들거나 원본 로그를 수정하지 않았다.

20km/h에서는 정지 관측기의 명령 시각이 제동시험 이벤트보다 약 9.651ms 뒤로 갱신됐다.
제동 명령 직후 이전 주행 명령의 송신 관측이 섞인 기록이 있고, 시험 노드의 결과 발행 조건은
두 명령 시각의 정확한 일치를 요구한다. 복사된 당시 README의 참고거리 약 6.692m는
관측기 송신 위치 기준 값으로, 이번 최초 명령 위치 기준 재구성값과 기준이 다르다.

## 해석 제한

- 위 값은 **명령 발행부터 GNSS 정지 위치까지의 거리**다. 실제 브레이크 작동 개시 시각은
  기록되지 않았으므로 순수한 기계 제동거리와 구분한다.
- GNSS 위치와 속도는 평균 약 20Hz이나 분석 구간 최대 표본 간격은 약 0.26~0.29초다.
  명령 이후 속도 상승을 모두 액추에이터 지연으로 단정할 수 없다.
- 제동 구간의 위치 공분산은 축별로 10km/h `0.0004m²`, 20km/h `0.64m²`,
  30km/h `2.25m²`다. 이는 기록된 불확실성 정보이며 실제 거리 오차를 실측한 값은 아니다.
  세 기록에 `/gnss/fix`·`/gnss/status`가 없어 실제 RTK 상태는 별도로 확인할 수 없다.
- GNSS 속도 적분 거리는 각각 약 2.88·7.30·11.60m로, 위치 직선거리와 약 3~9% 차이가 있다.
- 속도별 목표 도달 시험은 각 1회다. 40·50km/h의 완료된 목표 도달 시험은 없으며,
  이 세 점만으로 반복성이나 고속 제동거리를 확정하지 않는다.
