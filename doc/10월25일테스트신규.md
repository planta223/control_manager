공통 준비를 마친 컨테이너에서 아래 블록 전체를 실행한다. 실행 설정은 사본으로 저장한다.

```bash
(
set -e
cd /workspace
source /opt/ros/humble/setup.bash
source /workspace/install/setup.bash
export TEST_ROOT=/workspace/log/autonomy_new_20261025
export ROS_LOG_DIR="$TEST_ROOT/ros/$(TZ=Asia/Seoul date +%Y%m%dT%H%M%S)-$$"
mkdir -p "$TEST_ROOT" "$ROS_LOG_DIR"
CONTROL_TRIAL_DIR=$(mktemp -d "$TEST_ROOT/config-XXXXXX")
export CONTROL_TRIAL_OPERATION="$CONTROL_TRIAL_DIR/operation.yaml"
python3 -B - <<'PY'
import os
from pathlib import Path
import yaml

source = Path('/workspace/src/control_manager/config/modes/preliminary_lap.yaml')
data = yaml.safe_load(source.read_text())
common = data.setdefault('/**', {}).setdefault('ros__parameters', {})
common.update(mission_limit_enabled=False, mission_sections_enabled=False, object_state_enabled=False)
data['/control/vehicle_interface']['ros__parameters']['dry_run'] = False
data['/control/control_selector']['ros__parameters']['start_paused'] = True
Path(os.environ['CONTROL_TRIAL_OPERATION']).write_text(yaml.safe_dump(data, allow_unicode=True, sort_keys=False))
PY
# --cruise-speed-kph: 최고속도(km/h)
# --max-accel-kphps / --max-decel-kphps: 일반 속도 명령 증감률((km/h)/s)
# --planned-decel-kphps: 곡선·종점 감속거리 계산값; max-decel 이하
# --steering-zero-deg: 실측 직진 조향 영점(도, +좌/-우)
# --max-path-distance-m: 경로 이탈 허용 거리(m), 0=거리 제한 해제, 생략=YAML 기본값
# --heading-bootstrap-timeout-s: 최초 heading 확보 전 직진 허용시간(초), 양수, 기본 10초
# --stopped-heading-max-distance-m: 저장 heading 재개 허용 변위(m), 0=거리 제한 해제
# --stopped-heading-max-reacquire-time-s: 이동 후 heading 재확보 제한(초)
# --variable-speed: 곡률·종점 감속 활성화; 생략하면 고정 목표속도
ros2 run control_manager control_console \
  --mode preliminary_lap \
  --operation-file "$CONTROL_TRIAL_OPERATION" \
  --map-file /workspace/decision/script/map_generator/test/review/maps/MAP_preliminary.json \
  --variable-speed \
  --cruise-speed-kph 25.0 \
  --max-accel-kphps 2.0 \
  --max-decel-kphps 2.0 \
  --planned-decel-kphps 2.0 \
  --steering-zero-deg 0.0 \
  --max-path-distance-m 0 \
  --heading-bootstrap-timeout-s 10.0 \
  --stopped-heading-max-distance-m 0 \
  --stopped-heading-max-reacquire-time-s 3.0 \
  --stop-speed-mps 0.1 \
  --stop-hold-s 0.5 \
  --heading-bootstrap-timeout-s 5.0 \
  --log-root "$TEST_ROOT/console"
)
```

차량 방향·경로 합류 구간을 확인하고 `일시정지 상태로 준비됐습니다.`가 표시되면 출발한다.
위 명령은 경로와 멀어도 거리 때문에 정지하지 않는다. 경로 합류 구간을 확인하고 출발한다.
초기 직진은 지정 시간 이내라도 유효 heading이 확보되면 경로 추종으로 전환한다. 시간 안에 확보하지 못하면 정지한다.
이미 실행 중이면 `2/P` → `3/Q`로 종료한 뒤 변경된 블록을 재실행한다. 현재 설치는 소스 링크 방식이므로 이 옵션 추가에 재빌드는 필요 없다.

| 키 | 동작 |
|---|---|
| `1` / `R` | 출발·재개 |
| `2` / `P` | 모터 0·브레이크 ON |
| `0` / `C` | 모터 0·브레이크 OFF, 경로 추종 조향 유지 |
| `3` / `Q` / `Ctrl+C` | 정지 요청·실측 정지 확인 후 종료 |

정지/재개: `2/P` → 실제 정지 확인 → 전방 확인 → `1/R`. 우회전 대기는 실제 정지 후 3초 이상 유지한다.
비상 시 물리 E-stop을 사용한다. SSH 단절 시 키 전달은 보장되지 않는다.
