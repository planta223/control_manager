## 1. 속도 조절

최하단 원격 명령의 변수 네 개를 수정한다.

| 변수 | 기본값 | 의미 |
|---|---:|---|
| `SPEED_KPH` | 35.0 | 목표속도 상한, km/h |
| `MAX_ACCEL_KPHPS` | 2.0 | 속도 명령 증가율, (km/h)/s |
| `MAX_DECEL_KPHPS` | 2.0 | 일반 속도 명령 감소율, (km/h)/s |
| `PLANNED_DECEL_KPHPS` | 2.0 | 곡선·종점 감속거리 계산값, (km/h)/s |

`--variable-speed`이므로 곡선·종점에서는 상한보다 낮은 목표속도가 계산된다.
계획 감속도는 일반 감속도 이하여야 한다. 값은 모두 양수로 지정한다.
실행 중 속도 변경 키·파라미터 변경은 지원하지 않는다. `3/Q`로 종료한 뒤 값을 바꿔 재실행한다.
설정은 목표속도 기준이며 실제 속도 추종은 모터 튜닝 상태에 따라 달라진다.

## 4. 조작·종료

| 키 | 동작 |
|---|---|
| `1/R` | 출발·재개 |
| `2/P` | 모터 0·제동 정지 |
| `0/C` | 모터 0·브레이크 OFF, 경로 추종 조향 유지 |
| `3/Q` | 정지 요청·실측 정지 확인 후 콘솔 종료 |

원격 `3/Q`로 종료 → 터미널 9 `q` → 터미널 4 `q` → 같은 시험 이름으로 저장 → 센서·송신기 종료.
카메라 기록을 닫을 때까지 카메라는 켜 둔다.

호스트 저장 위치:

```text
/home/baqu4/Workspaces/2026WS/main/log/final_lap_20261025/
  records/         센서·제어·신호·송신 이벤트
  camera_records/  압축 영상 원본·촬영 시각
  console/         실행 명령·지도·설정·키 조작
  ros/             터미널별 로그
```

컨테이너에서 아래 전체를 실행한다. 재실행할 때마다 최신 본선 설정의 새 사본을 만든다.
시작은 일시정지 상태다. 최초 연결은 경로 첫 10m이며 이후 진행 순서를 유지한다.
`--max-path-distance-m 0`은 거리 제한 해제다. 지도 첫 점까지 약 58m였던 이전 출발 위치의 시험값을 유지한다.

```bash
(
set -e
cd /workspace
source /opt/ros/humble/setup.bash
source /workspace/install/setup.bash
export TEST_ROOT=/workspace/log/final_lap_20261025
export ROS_LOG_DIR="$TEST_ROOT/ros/remote-$(TZ=Asia/Seoul date +%Y%m%dT%H%M%S)-$$"
mkdir -p "$TEST_ROOT" "$ROS_LOG_DIR"

SPEED_KPH=35.0
MAX_ACCEL_KPHPS=2.0
MAX_DECEL_KPHPS=2.0
PLANNED_DECEL_KPHPS=2.0

CONTROL_TRIAL_DIR=$(mktemp -d "$TEST_ROOT/config-final-XXXXXX")
export CONTROL_TRIAL_OPERATION="$CONTROL_TRIAL_DIR/operation.yaml"
python3 -B - <<'PY'
import os
from pathlib import Path
import yaml

source = Path('/workspace/src/control_manager/config/modes/preliminary_lap.yaml')
data = yaml.safe_load(source.read_text())
common = data.setdefault('/**', {}).setdefault('ros__parameters', {})
common.update(traffic_enabled=True, mission_limit_enabled=False, mission_sections_enabled=False, object_state_enabled=False)
data['/control/vehicle_interface']['ros__parameters']['dry_run'] = False
data['/control/control_selector']['ros__parameters']['start_paused'] = True
Path(os.environ['CONTROL_TRIAL_OPERATION']).write_text(yaml.safe_dump(data, allow_unicode=True, sort_keys=False))
PY

ros2 run control_manager control_console \
  --mode preliminary_lap \
  --operation-file "$CONTROL_TRIAL_OPERATION" \
  --map-file /workspace/decision/script/map_generator/test/review/maps/MAP_preliminary.json \
  --variable-speed \
  --cruise-speed-kph "$SPEED_KPH" \
  --max-accel-kphps "$MAX_ACCEL_KPHPS" \
  --max-decel-kphps "$MAX_DECEL_KPHPS" \
  --planned-decel-kphps "$PLANNED_DECEL_KPHPS" \
  --steering-zero-deg 0.0 \
  --max-path-distance-m 0 \
  --heading-bootstrap-timeout-s 10.0 \
  --stopped-heading-max-distance-m 0 \
  --stopped-heading-max-reacquire-time-s 3.0 \
  --stop-speed-mps 0.1 \
  --stop-hold-s 0.5 \
  --log-root "$TEST_ROOT/console"
)
```
