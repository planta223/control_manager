# 원격PC 조작법

| 키 | 동작 |
|---|---|
| 0 / C | 모터 명령 0·브레이크 OFF, 경로 추종 조향 계속 |
| 1 / R | 출발·재개 |
| 2 / P | 모터 명령 0·브레이크 ON으로 일시정지 |
| 3 / Q / Ctrl+C | 모터 명령 0·브레이크 ON 후 정지 확인·종료 |

정지·재개: 정지 목표보다 앞에서 2/P → 차량이 실제로 멈춘 것을 확인 → 전방 확인 → 1/R.
모터 구동을 먼저 0으로 두려면 0/C → 별도로 제동할 때 2/P를 누른다. 1/R은 모터 구동을 재개한다.
0/C 중에도 센서 이상·경로 이탈·종점 등 기존 보호 정지는 브레이크 ON을 적용한다.
모터 0은 RPM 명령 0을 뜻하며, 실제 감속·회생제동 여부는 모터 제어기 응답을 확인한다.
정지 기준은 유효 GNSS 속도 0.1m/s 이하가 0.5초 지속되는 것이다. 정지 중 마지막 조향은 유지된다.
코스 중간에서는 제어 노드를 재시작하지 않는다.

# 주행완료후 원격PC 종료(3/Q) → 실제 정지·콘솔 종료 확인 → 터미널 4 에서 q 이후 y/n → y이면 시험 이름 입력 → 터미널 6 Ctrl+C

주행 시 확인할 사항은 다음과 같다.

1. 지도·시작점·주행 방향·조향 영점·배터리·비상정지·SSH 응답을 확인한다. 정지 요청 위치는 실측 정지거리보다 여유 있게 정한다.
2. 예선 지도는 5,032점용 진행 위치 프로필을 사용한다. 다른 지도에는 그대로 적용하지 않는다.
3. 본선은 `final_lap.yaml`의 `MAP_final.json`, 제동검차는 `brake_inspection.yaml`의 `MAP_brake.json`을 사용한다. 현재 본선 지도는 있고 검차 지도는 아직 없으므로, 검차 지도 저장 후 해당 모드로 실행한다. 경로·시작점·주행 방향을 확인하고 교차 구간이 있으면 진행 위치 추적도 확인한다.
4. 최초 heading 확보에는 실제 속도 0.7m/s(2.52km/h) 이상이 필요하다. 초기 직진은 최대 10초이므로 시작 방향과 확보 구간을 확인한다.
5. 위 명령은 저장 heading의 거리 제한을 0으로 해제하고, 실측 이동 시작 후 3초의 시간 제한을 사용한다. 새 유효 heading이 없을 때 시간 한계에 도달하면 정지하며, 재개 키를 반복해 우회하지 않는다.
6. 저속 정지·재개가 확인되기 전 속도를 올리지 않는다. 위 명령은 20km/h를 상한으로 곡선·종점 앞 감속을 계획한다. 명령 감소율과 실제 감속 성능은 구분해 확인한다.
7. SSH 단절·제동 무응답·과속·경로 이탈·센서 또는 조향 이상 시 중단한다. 긴급 시 하드웨어 비상정지를 사용한다.
8. 종점 완료·비상정지 후 새 회차는 원인과 차량 상태를 확인하고 경로 시작점에서 준비한다. 정지 중 차량을 밀거나 돌린 경우도 같다.

# 23일 종가속도/종감속도 명령에 --feedback-source motor_rpm을 추가한다. GNSS는 필요 없다.
# 시작·끝 명령은 기존 km/h→RPM 환산 그대로이며, 실제 차량 속도를 뜻하지 않는다.

# 터미널 1 - 모터피드백 (이미 실행 중이면 유지)
ros2 run encoder_motor motor_rpm

# 터미널 2 - 기록 + 실차 송신 (기존 trans와 중복 실행하지 않는다)
ros2 launch manual_control brake_test_support.launch.py \
  live:=true \
  log_root:=/workspace/log/vehicle_recorder

# 터미널 3 - 기존 가감속시험 + RPM 판정 선택
# 0→시작 명령 5초 상승 → 최소 3초 유지·RPM 안정화
# → 끝 명령으로 2초 전환 → 최소 3초 유지·RPM 안정화 → 최종 제동
ros2 run manual_control brake_step_test \
  --speed-transition \
  --feedback-source motor_rpm \
  --start-speed-kph 10.0 \
  --end-speed-kph 5.0 \
  --startup-time-s 5.0 \
  --transition-time-s 2.0 \
  --hold-time-s 3.0 \
  --acceleration-timeout-s 30.0 \
  --steering-deg 0.0 \
  --ros-args \
  -p settle_window_s:=0.5 \
  -p settle_range_rpm:=5.0 \
  -p settle_slope_rpm_s:=2.0 \
  -p cmd_topic:=/cmd

R 정지 확인 후 시작, Enter/Space 모터 0·브레이크 ON, Q/Ctrl+C RPM 정지 확인 후 종료.

- 정착: 0.5초 이상·새 표본 6개 이상에서 RPM 변동폭 5 이하, 기울기 절댓값 2RPM/s 이하. 목표 RPM과의 일치는 요구하지 않는다.
- 정지: 유효 피드백 절댓값 1RPM 이하가 0.5초 지속. 회전 중 최소 5RPM 미만은 정착으로 인정하지 않는다.
- 현재 보정 RPM 펌웨어를 사용한다. 기본 전진 피드백 부호는 음수이며 `motor_feedback_sign:=-1.0`으로 맞춘다. 보정계수를 다시 곱하지 않는다.
- 피드백 무효·측정시각 정체·수신 끊김은 정지 요청으로 처리하며, 피드백 상실을 정지 완료로 간주하지 않는다.
- 콘솔과 기록에서 명령/피드백 RPM, 전환 전후 정착 RPM, RPM 변화율, 명령 오차를 확인한다.

종료: result/COMPLETE 확인 → 터미널 3 Q → 터미널 2 q → y/n·기록 이름 입력.
기록 검토 후 지원 launch의 trans도 자동 종료한다. 기록 이름 예: `무부하_RPM_10to5_01`.
