## 시험 동작과 키

| 키 | 동작 |
|---|---|
| R | 정지 확인 후 조향 0, 목표속력에 해당하는 모터 RPM을 step으로 설정 |
| Enter / Space | 모터 0·브레이크 ON 유지 |
| Q / Ctrl+C | 제동 후 정지가 확인되면 종료 |

R 이후에는 W/S를 누를 필요가 없다. 고정된 속도 기준 명령을 100Hz로 반복 발행한다.
실제 CAN 전송 주기는 모터 펌웨어의 기존 20Hz다. 가속 ramp는 이번 시험 경로에 넣지 않는다.
GNSS의 **전진 속도**가 목표 ±0.5km/h 안에서 **1.0초 연속 유지**되면 자동으로
모터 0·브레이크 ON으로 바꾸고, 정지 결과 `result`를 출력한다.
단순히 목표속력을 처음 넘는 순간에는 제동하지 않는다.
정지 판정은 기존과 같이 |속도| ≤0.1m/s가 0.5초 유지되는 구간의 시작이다.
같은 목표속력을 반복하려면 `R 시작 가능`을 확인하고 다시 R을 누른다.

### 설정 및 속도 환산

기본값은 현재 선택한 Arduino UNO 4500RPM 펌웨어 기준이다.
모터 펌웨어의 SPEED_MAX_RPM과 `motor_full_scale_rpm`을 반드시 일치시킨다.
차속→RPM은 바퀴 지름 0.47m, 모터/바퀴 회전비 1.0을 사용하며,
이 값들은 현재 vehicle.yaml과 같지만 지름은 아직 임시 측정값이다.
PC에는 GNSS 속도를 목표에 맞추는 PID를 추가하지 않았다. 고정 RPM 기준을 보내고
실제 GNSS 속도의 안정화 여부를 관측하는 시험이다.

PC는 속도 필드를 **float32 -100~100**으로 송신하고, UNO는 최종 CAN 명령에서만
1RPM 단위로 반올림한다. 송수신 형식은 `<ffB>`이며 이전 int32 속도 펌웨어와 섞어 쓰지 않는다.
현재 기본 설정에서 10km/h 요청은 송신 약 2.508352, 최종 기준 113RPM,
기하학적 환산 약 10.011km/h다. 화면에는 float32 송신값과 최종 RPM 환산속력을 표시한다.
실제 GNSS 속력은 별도로 확인한다. 부하·환산 오차 등으로 요청 범위에 안정화되지 않으면
30초 후 제동하고 `acceleration_timeout`으로 기록하며 정상 제동거리로 사용하지 않는다.

옵션을 바꾸려면 위 터미널 5 명령에 필요한 항목만 추가한다.

```bash
-p settle_tolerance_kph:=0.5
-p settle_hold_s:=1.0
-p acceleration_timeout_s:=30.0
-p motor_full_scale_rpm:=4500.0
-p wheel_diameter_m:=0.47
-p motor_to_wheel_ratio:=1.0
```

목표 범위 밖으로 나가면 안정화 대기는 처음부터 다시 센다.
GNSS 이상/0.3초 갱신 중단, 터미널 입력 감시 중단/연결 종료, 수동 중단 시에는 제동하며,
시간 초과나 중단 시험은 `target_stabilized` 정상 시험과 구분한다.
브레이크 이후에는 같은 키 입력으로 가속을 재개하지 않는다.
ASMS AUTO 권한 등 기존 실차 송신 조건은 그대로 필요하다.

## 기록 및 결과 저장

터미널 4의 기록은 호스트 `main/log/vehicle_recorder/braking/<시험별 폴더>/`에 남는다.
GNSS odom/fix/status, 모터·조향 피드백, 제동 시험 설정·이벤트,
명령 발행/송신 이벤트, 정지 관측을 함께 기록한다. 시험 코드와 launch 사본도 보존한다.
정상 결과의 reason은 `target_stabilized`이며 실제 제동 직전 속력은
`observed_speed_kph`로 확인한다. 목표값만으로 측정 속력을 대체하지 않는다.
거리는 원래 제동 명령 위치부터 정지 위치까지의 직선거리다.
명령/송신 관측 순서가 섞이면 `observer_command_ns`도 별도로 남기고,
원래 명령 위치를 GNSS 보간으로 복원한다. 보간할 수 없으면 거리는 null이다.

모든 시험 후 터미널 5를 Q로 종료한 뒤 터미널 4를 Ctrl+C로 닫는다.
그다음 main 컨테이너에서 CSV를 저장한다.

```bash
ros2 run manual_control brake_report \
  /workspace/log/vehicle_recorder/braking/*/messages.jsonl \
  --output "/workspace/log/vehicle_recorder/braking/brake_results_$(date +%Y%m%d_%H%M%S_%N).csv"
```

`completed=true`와 `target_reached=true`인 행을 정상 안정화 후 제동 시험으로 사용한다.
거리 유효 여부와 metadata.json의 complete/dropped/errors도 함께 확인한다.
실차 전송 없는 미리보기는 터미널 4에서 `live:=false`, 터미널 5에서
`cmd_topic:=/brake_test/preview_cmd`로 양쪽을 맞춘다. 미리보기는 차량을 움직이지 않는다.
