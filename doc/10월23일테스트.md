**# 터미널 5 - 종감속도 시험 조작**
# --speed-transition : 두 기준 차속 사이 전환 시험 (기본값 OFF)
# --start-speed-kph : 전환 전 차속 명령(km/h) (기본값 10) (상한 약 78.97)
# --end-speed-kph : 전환 후 차속 명령(km/h) (기본값 5) (상한 약 78.97, 0 초과·시작값과 다르게)
# --startup-time-s : 0에서 시작 차속까지 상승시간(s, 0=STEP) (기본값 5) (상한 미설정)
# --transition-time-s : 두 기준 사이 상승/하강시간(s, 0=STEP) (기본값 2) (상한 미설정)
# --hold-time-s : 각 상승/하강 완료 후 최소 기준 명령 유지시간(s, 0 초과) (기본값 3) (상한 미설정)
# --acceleration-timeout-s : R부터 강제 제동까지 제한시간(s, 상승·전환·유지·안정화 대기 포함) (기본값 30) (상한 미설정)
# settle_window_s : GNSS 속도 안정화 최소 구간(s, 표본 6개 이상) (기본값 0.5) (상한 acceleration_timeout_s 미만)
# settle_range_kph : 안정화 구간의 속도 최대-최소 허용값(km/h) (기본값 0.5) (상한 미설정)
# settle_slope_kph_s : 안정화 구간의 속도 기울기 절댓값 허용값((km/h)/s) (기본값 0.2) (상한 미설정)
# --steering-deg : 고정 조향각(°,+좌/-우) (기본값 0) (범위 -17.01~17.01)
# 0→10km/h 5초 상승 → 최소 3초 유지·GNSS 안정화 → 10→5km/h 2초 하강 → 최소 3초 유지·GNSS 안정화 → 최종 제동.
# 유지시간 경과와 GNSS 안정화를 모두 확인한다. 제한시간 초과·오류·수동 정지는 강제 제동이며 정상 완료가 아니다.
# 하강·마지막 유지 구간은 브레이크 OFF이며, 이 구간의 GNSS 감속도에 최종 제동은 포함하지 않는다.
# !!!!! R 시작, Enter/Space 즉시 제동, Q 정지 확인 후 종료 !!!!!
ros2 run manual_control brake_step_test \
  --speed-transition \
  --start-speed-kph 10.0 \
  --end-speed-kph 5.0 \
  --startup-time-s 5.0 \
  --transition-time-s 2.0 \
  --hold-time-s 3.0 \
  --acceleration-timeout-s 30.0 \
  --steering-deg (여기값수정) \
  --ros-args \
  -p settle_window_s:=0.5 \
  -p settle_range_kph:=0.5 \
  -p settle_slope_kph_s:=0.2 \
  -p cmd_topic:=/cmd

# 전환 시작/끝, GNSS 응답 구간 평균·회귀 감속도((km/h)/s), 속도 적분 주행거리(m)를 기록한다.
# 응답 구간은 하강 시작 후부터 마지막 유지 종료 전까지이며, 명령과 실측 속도의 일치는 요구하지 않는다.
# response_valid/transition_completed와 원본 GNSS 기록을 함께 확인한다. 감속도는 m/s² 단위로 보려면 3.6으로 나눈다.
# result/COMPLETE 확인 → 터미널 5 Q 종료 → 터미널 4 q 이후 기록 이름 입력.

**# 터미널 5 - 자율주행 조작**
# --variable-speed   : 번속 혀용 (기본값 OFF)
# --cruise-speed-kph : 최고속도 상한 (기본값 20km/h) (상한 78.97km/h)
# --max-accel-kphps  : 모든 속도 증가 구간의 명령 가속도 상한 (기본값 10km/hs) (상한 10km/hs)
# --max-decel-kphps  : 일반 속도 감소 구간의 명령 감속도 상한 (기본값 0=미정) (상한 미설정)
# --planned-decel-kphps : 감속계획 가정값((km/h)/s) (기본값 명령 감속도) (상한 명령 감속도)
# --max-lateral-accel-mps2 : 횡가속도 상한(m/s²) (기본값 1.96133m/s^2) (상한 1.96133m/s^2)
# --steering-zero-deg : 정렬 시험에서 직진한 조향각(°,+좌/-우), 자율주행 0° 보정값 (기본값 0) (범위 -17.01 초과~17.01 미만)
# 가속/감속/횡가속도는 실측 보장값이 아니다.
# --variable-speed에서는 가감속 상한을 Motion Planning과 최종 명령 제한에 함께 적용한다.
# 출발/재개는 GNSS 속도에서 계획을 시작하며, 일시정지 중에는 가속 계획도 초기화한다.
# 정지/제동/입력 오류는 제한을 우회해 즉시 적용한다.
# 실행만으로 출발하지 않는다. 일시정지 상태로 준비된 뒤 1을 눌러 출발한다.
ros2 run control_manager control_console \
  --mode test \
  --variable-speed \
  --cruise-speed-kph 25 \
  --max-accel-kphps 5 \
  --max-decel-kphps 5 \
  --planned-decel-kphps 3 \
  --steering-zero-deg 0.0 \
  --max-lateral-accel-mps2 1.96133

# 직선에서 최고속도까지 가속하고 곡선/종점 전에 낮은 목표속도로 이행한다.
# 감속거리 계획은 지도 전체를 사용하며, 조향 lookahead는 계속 GNSS 실측 속도로 계산한다.
# response_time_s=0.5는 미측정 지연 가정이다. 실제 감속/속도 준수 여부는 GNSS로 확인한다.
