조작 키는 다음과 같다.
키	동작
------------
R	정지 확인 후 시험 시작. 조향 0·모터 0에서 시작
W / S	모터 출력 증가 / 감소
A / D	조향 조정
C	주행 중 조향 중앙
Enter / Space	마지막 조향 유지·모터 0·브레이크 ON 고정
Q / Ctrl+C	정지 요청 후 정지 확인까지 기다려 종료

목표 도달 후 result와 정지 확인을 기다립니다.
다른 목표 속도를 시험하려면 Q로 클라이언트를 종료하고 --target-kph를 바꾸어 다시 실행합니다.
모든 시험이 끝나면 클라이언트를 Q로 종료합니다.
차량 측 제동시험 지원 launch를 Ctrl+C로 종료해 기록을 닫습니다.
그다음 CSV 추출 명령을 실행합니다.

조작 키는 아래와 같다.
키		동작
------------------------------
1 또는 r	출발·재개
2 또는 p	일시정지
3 또는 q	정지 확인 후 종료

출발 절차는 아래 사항을 따른다.
센서 실행
→ 모니터·기록 실행
→ control_console 실행: 일시정지 상태로 준비
→ trans 실행
→ 지도와 입력 상태 확인
→ control_console에서 1 또는 r

종료 절차는 아래 사항을 따른다.
control_console에서 3 또는 q
→ 실제 정지 확인 및 메뉴 종료까지 GNSS·trans 유지
→ trans를 Ctrl+C로 종료
→ 기록기를 Ctrl+C로 종료
→ 모니터·센서 종료
