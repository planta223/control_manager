# 10월 25일 신호 구독·기록

```text
baqu_traffic_light
  /sensors/detectTraffic [control_manager/msg/TrafficLight]
    → sensor_interface
      → /control/sensors/traffic [같은 메시지]

vehicle_recorder: 위 두 토픽을 각각 기록
```

예선·본선의 `traffic_enabled: true`를 사용한다. `object_state_enabled`,
`mission_limit_enabled`, `mission_sections_enabled`, `traffic_light_applies`는 false를 유지한다.
신호 상태로 속도·조향·제동을 변경하지 않는다.

기존 터미널 4 기록을 종료한 뒤 새로 실행한다. 설정·Python 소스 링크 변경이므로 재빌드가 필요 없다.

```bash
  --params-file /workspace/src/control_manager/config/record_test.yaml \

```

터미널 7도 다시 실행하면 Sensor Interface가 신호 토픽을 구독한다.
인식기가 켜진 뒤 기록 터미널에서 다음 두 구독 메시지를 확인한다.

```text
Recording serialized /sensors/detectTraffic [control_manager/msg/TrafficLight]
Recording serialized /control/sensors/traffic [control_manager/msg/TrafficLight]
```

## 수신 확인

```bash
ros2 topic info /sensors/detectTraffic --verbose
ros2 topic info /control/sensors/traffic --verbose
timeout 5s ros2 topic echo /sensors/detectTraffic --once
timeout 5s ros2 topic echo /control/sensors/traffic --once --qos-reliability best_effort
```

인계본 출력은 reliable/depth 1, 20Hz다. Sensor Interface는 best effort로 구독·relay한다.
`traffic_id`는 인계본이 채우지 않아 0이며, 원본 timestamp·status·valid·color_confidence를
변경하거나 Unknown/invalid를 버리지 않는다. 동일 영상 근거를 20Hz로 재발행한 결과도 모두 기록한다.
`complete` 외에 metadata의 토픽별 수신·저장 건수와 `undiscovered_topics`를 확인한다.
인식기가 없으면 신호 토픽은 미발견으로 남는다. 이것만으로 제어를 정지시키지 않는다.

## 인식기 실행 환경

인계본 위치:

```text
/workspace/traffic_sign/CONTROL_TEAM_HANDOFF_20261025/CONTROL_TEAM_HANDOFF_20261025/baqu_traffic_light
```

인식기는 별도 프로세스로 실행하며 카메라 `/camera/image_raw`를 사용한다.
main에 `baqu_traffic_light`와 `/workspace/traffic_sign/.venv` 설치 완료.
CUDA PyTorch 2.4.1+cu121, torchvision 0.19.1+cu121, Ultralytics 8.4.107을 사용한다.
시스템 Python·lane_AI 환경은 유지했다. 모델 해시, cv_bridge 변환, 합성 영상 GPU 추론,
카메라 미입력 시 20Hz 발행과 입력 만료 시 invalid 전환을 격리 환경에서 확인했다.

```bash
source /opt/ros/humble/setup.bash
source /workspace/install/setup.bash
ros2 launch baqu_traffic_light traffic_light.launch.py
```

설치 후 이미 열려 있던 터미널도 setup을 다시 source한다. 별도 venv 활성화는 필요 없다.
재설치는 `bash /workspace/tools/setup_traffic_sign.sh`를 사용한다.
